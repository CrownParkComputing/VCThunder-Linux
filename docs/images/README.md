# Documentation images

The SVG banner, setup flow and cabinet-layout diagram are project-authored
vector illustrations. They can be edited directly as SVG source.

`first-run-setup.png` and `nuklear-menu.png` are captures of the actual native
Linux UI. `dual-screen.jpg` and `four-player.jpg` show separate native Offroad
game processes in shared local races. Capture sessions use isolated saves and
synthetic control input. They do not establish four-pad hardware compatibility.

Screenshots contain only game/application windows, with no surrounding
desktop applications. The game artwork belongs to its original owners; these
images document port behavior and do not include playable game assets.

The source scanner permits these four named screenshot paths. Other binary
game data, archives, libraries, saves and disk images remain excluded.
